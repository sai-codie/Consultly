## Project Description
The Student Consultation Booking System is a web-based project developed by Undefined, a team of Software Engineering students from Universiti Utara Malaysia (UUM), as part of the STIWK2014 Software Engineering (A) course.

The system aims to streamline student–lecturer interactions through centralized appointment scheduling, real-time consultation slot availability, and structured booking management. By improving consultation accessibility, preventing scheduling conflicts, and simplifying appointment coordination, the platform provides a more efficient, transparent, and user-friendly consultation experience.
